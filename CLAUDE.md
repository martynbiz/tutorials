# Tutorials

## Where things go

Each tutorial series has its own folder, for example `java/spring-boot/consuming-apis/` or `java/lib-gdx/top-down-player-movement/`. A series folder holds:

- `README.md`: the series overview
- `01-….md`, `02-….md` and so on: the guides, in order
- `SPEC.md`: the series' spec (PRD), if it has one
- `PLAN.md`: the series' implementation plan, if it has one

Put a series' spec and plan in **that series' folder** as `SPEC.md` and `PLAN.md`, not in a shared top-level `specs/` folder.
